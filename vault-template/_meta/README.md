# Workspace vault

This is the shared Markdown memory for the workspace. It is a git repository; every change is a commit
whose author says whether a person or an agent made it.

| Folder | Holds |
|---|---|
| `_meta/` | Vault rules (`AGENTS.md`, human-edit only) and this file |
| `agents/` | One note per agent |
| `skills/` | Skill notes |
| `projects/` | Project notes |
| `tasks/` | Task notes |
| `inbox/` | New, unsorted notes |
| `logs/` | Run and activity logs |
