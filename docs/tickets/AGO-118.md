# AGO-118 - Add the Playwright end-to-end harness

## Overview

Jira AGO-118 (US-018), epic EP-00, wave 1. Adds Playwright with a smoke test and runs it in CI against a production build. Blocked by AGO-92 (Done). Risk tier: medium (touches CI and adds a dev dependency; no data, auth or AI-safety surface). The PR changes `.github/workflows/ci.yml`, so the owner merges it.

## Implementation details

- `@playwright/test` pinned to `1.64.1` (exact, released 2026-10-14) as a dev dependency of `@ago/web`.
- `apps/web/playwright.config.ts`: `testDir: ./e2e`; serves the production build with `next start --hostname 127.0.0.1 --port $PORT` (default 3100, `reuseExistingServer: false`); `trace`/`screenshot`/`video` kept on failure only; Chromium project, Microsoft Edge locally (`E2E_BROWSER_CHANNEL` overrides); `forbidOnly` and one retry in CI.
- `apps/web/e2e/fixtures/index.ts`: shared `test`/`expect` with an automatic guard that fails any test whose page logs a console error or throws (opt-out per spec through `allowedConsoleErrors`).
- `apps/web/e2e/pages/home-page.ts`: first page object. `apps/web/e2e/smoke.spec.ts`: home page loads (2xx), title and h1 are "Agent Office", no console errors.
- `apps/web/src/app/icon.svg`: the smoke test's console guard caught `GET /favicon.ico` returning 404; adding an app icon fixes the cause instead of allow-listing the error.
- Scripts: `test:e2e` in `apps/web` and at the root (`turbo run test:e2e`). Turbo task `test:e2e` depends on `build`, is not cached, and passes through `CI`, `PORT`, `E2E_BROWSER_CHANNEL`.
- `.github/workflows/ci.yml`: new job `test-e2e` (stable name): SHA-pinned actions, inherited read-only permissions, 20 minute timeout, Playwright browser cache keyed on the Playwright version, `playwright install --with-deps chromium`, placeholder env (`APP_ENV=local`, local public URLs). A final step with `if: failure()` uploads `apps/web/test-results/` and `apps/web/playwright-report/` with `actions/upload-artifact` (SHA-pinned, 7 day retention).
- Docs: `docs/testing.md` (how to run and write specs), the tester brief (`pnpm test:e2e` now exists), `docs/ai-workflow.md`, `CONTRIBUTING.md`. `.gitignore` ignores `apps/web/e2e/.auth/`.

## Decisions taken (no human at the keyboard; recommended option picked)

| Decision                | Chosen                                                                  | Why                                                                                                                      |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Where the harness lives | `apps/web/e2e` + `apps/web/playwright.config.ts`                        | It tests the web app and shares its tsconfig, eslint and `next start`; a package would add a workspace for one consumer. |
| "Preview build"         | Production build (`next build`, `next start`) served inside CI          | Coordinator note: no hosted Vercel preview (hosted/paid decision for the owner).                                         |
| Playwright version      | Exact `1.64.1`                                                          | Latest stable, three weeks old; exact pin for supply-chain reproducibility.                                              |
| Browser                 | Chromium in CI, Edge (`msedge`) locally, `E2E_BROWSER_CHANNEL` override | Edge is installed on the Windows dev machine, Chrome is not.                                                             |
| Build in the E2E task   | Turbo `dependsOn: ["build"]`, `cache: false` for the E2E task           | One command (`pnpm test:e2e`) locally and in CI; build is still cached by Turbo; test results are never replayed.        |
| Server reuse            | `reuseExistingServer: false`                                            | Parallel worktrees run servers; attaching to another ticket's server would test the wrong code.                          |
| Console errors          | Auto fixture fails the test; per-spec allow-list                        | Meets the "no console errors" AC for every future spec, not just the smoke test.                                         |
| Favicon 404             | Add `src/app/icon.svg`                                                  | Fixes the real defect the guard found rather than hiding it.                                                             |
| Install in CI           | `pnpm --filter @ago/web exec playwright install --with-deps chromium`   | Same as `npx playwright install`, but resolves the pinned workspace version.                                             |
| Retries and workers     | 1 retry and 2 workers in CI, none locally                               | Absorbs infrastructure flakes without hiding real failures; traces are retained on failure either way.                   |
| Required check          | Not changed                                                             | Branch protection is human-only. Owner: add `test-e2e` to the required checks (list in `CONTRIBUTING.md`) after merge.  |

## Known limitations

- Trace upload is proven by configuration (`trace: "retain-on-failure"` plus an `if: failure()` upload step), not by a deliberately broken commit. Locally a failing run did write `trace.zip`, a screenshot and a video.
- Turbo strict env mode does not pass the job's placeholder `NEXT_PUBLIC_*` values to `next build`, only to `next start`. Fine today (the app reads no env); revisit when AGO-70 adds build-time env.
- Only Chromium (Edge locally); no Firefox or WebKit projects.
- Failure video needs a one-time local `playwright install ffmpeg` when using Edge or Chrome.
- No auth fixtures yet (AGO-67).
