## Implementation details
- `CLAUDE.md`: import line and pointer at the top; §10 now describes `/deliver`; `# Compact instructions` added (key AGO).
- `docs/workflow/README.md` and `REVIEW.md`: project values and the invariants reviewers check.
- `scripts/workflow/checks.mjs` holds the gate; `checks.sh` and `checks.ps1` are thin wrappers (one code path, reuse-first). Steps: `pnpm install --frozen-lockfile`, lint, typecheck, test, build, pgTAP, ticket record. A failing hard step stops the run. pgTAP runs under `scripts/db-lock.mjs` only if the local stack answers on 44321, otherwise it is skipped with a note (skips do not fail). The ticket record check needs `docs/tickets/<KEY>.md` with a `Ticket:` link, and a `PRs:` link once a PR exists on the branch (key from the branch name).
- `scripts/workflow/cost.mjs` (+ `cost` shim): sums usage from `~/.claude/projects/*<key>*` (the worktree's transcript folders, subagents included), de-duplicated by message id, priced from a table in the file; prints `cost: not tracked` when nothing is found. Unknown models are reported as unpriced.
- `scripts/workflow/workflow-scripts.test.mjs`: Vitest for the report format, record check, key parsing and cost maths (picked up by `vitest.scripts.config.mjs`).
- `.gitignore`: `.delivery/`. `docs/setup/local-backend.md`: stack, ports, db lock, seed, test account, free port.
- Legacy notices in `docs/ai-workflow.md`, `AGENTS.md` and the `run-waves` / `pr-gate` skill descriptions.

## Known limitations
- The gate runs `main`'s copy of the checks script, so the new script only takes effect after merge.
- Cost matches transcripts by worktree folder name containing the ticket key; sessions run elsewhere are not counted.
- Prices in `cost.mjs` are a point-in-time estimate.
